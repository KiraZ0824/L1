# 项目管理功能说明

## 页面概述

| 功能点 | 说明 |
|---|---|
| 页面入口 | 侧边栏 → 项目管理 |
| 页面 ID | `page-projects` |
| 页面标题 | 项目管理 |
| 副标题 | 项目列表 · 预算管控 · Backlog 规划 |
| 渲染函数 | `renderProjects()` |

## 项目统计指标

| 功能点 | 说明 |
|---|---|
| 活跃项目 | 当前处于调研/立项/执行阶段的项目数 |
| 总预算 | 所有项目预算总和（RP） |
| 已验收任务 | 已验收任务数 / 总任务数 |
| 预算使用率 | 已花费+冻结 占 总预算的百分比 |
| 渲染容器 | `projectStatsGrid` |

## 筛选与搜索

| 功能点 | 说明 |
|---|---|
| 关键词搜索 | `projectSearch` — 按项目名称/编号模糊搜索 |
| 状态筛选 | `projectStatusFilter` — 全部/调研阶段/立项阶段/项目执行/项目验收/项目结项 |
| 负责人筛选 | `projectLeadFilter` — 全部/张明远/李晓华/赵明/王思远/陈雨桐 |
| 排序 | `projectSort` — 按创建时间/按预算/按进度 |
| 列设置器 | `projectListBody_colsel` — 可自定义显示/隐藏列 |
| 触发方式 | 筛选条件变更即触发 `renderProjects()` |

## 项目列表表格

| 功能点 | 说明 |
|---|---|
| 项目名称 | 项目名称（加粗显示） |
| 编号 | 项目ID（P1格式，等宽字体） |
| 描述 | 项目描述（省略号截断） |
| 类型 | 内部项目/客户项目/研究项目 |
| 阶段 | 调研/立项/执行/验收/结项（带颜色圆点） |
| 负责人 | 项目负责人姓名 |
| 部门 | 所属部门 |
| 参与人数 | 项目成员人数 |
| 开始日期 | 项目开始日期 |
| 结束日期 | 项目结束日期 |
| 预算使用 | 进度条 + 百分比（>80%红色/>50%橙色/其他绿色） |
| 任务数 | 关联任务数量（可点击跳转任务管理） |
| 操作 | 追加奖励按钮（⋮菜单） |
| 分页 | 支持分页浏览，控件 `projectListBody_pager` |
| 行点击 | 点击行打开项目详情侧滑面板 `openProjectDetail(id)` |

## 创建项目

| 功能点 | 说明 |
|---|---|
| 入口 | 页面右上角「创建项目」按钮 → `openProjectModal()` |
| 弹窗类型 | 右侧抽屉面板（`createDrawerPanel`） |
| 项目名称 | 文本输入（必填，≤50字符） |
| 项目描述 | 文本域（必填） |
| 负责人 | 下拉选择（默认=创建者） |
| 所属部门 | 下拉选择：技术部/产品部/市场部/合规部/财务部 |
| 总预算 | 数字输入（必填，单位RP） |
| 项目状态 | 下拉选择：草稿/进行中/已完成/已归档 |
| 开始日期 | 日期选择（必填） |
| 结束日期 | 日期选择（必填） |
| 项目类型 | 下拉选择：内部项目/客户项目/研究项目 |
| 预计收益 | 数字输入（选填） |
| 预计成本 | 数字输入（选填） |
| Backlog 定义 | 可添加/删除阶段，编辑阶段名称和起止时间 |
| 项目成员 | 可选择多个成员 |
| 取消 | 关闭抽屉 |
| 创建项目 | 提交创建，提示成功 |

## Backlog 阶段定义

| 功能点 | 说明 |
|---|---|
| 默认阶段 | 调研阶段、立项阶段、项目执行、项目验收、项目结项 |
| 添加阶段 | 「+ 添加阶段」按钮 → `addBacklogStage()` |
| 阶段名称 | 可编辑文本 |
| 起止时间 | 每个阶段可设置开始和结束日期 |
| 排序 | 可拖拽排序 |
| 删除 | 可删除阶段 |
| 渲染容器 | `backlogStagesContainer` |

## 项目状态扭转说明

### 状态定义

| 功能点 | 说明 |
|---|---|
| 调研阶段 `research` | 项目初始阶段，进行可行性调研、需求分析和技术选型 |
| 立项阶段 `initiation` | 调研通过后立项，确定项目范围、预算分配和Backlog规划 |
| 项目执行 `execution` | 项目正式执行，任务分配、开发交付、进度跟踪 |
| 项目验收 `review` | 所有任务完成后进入验收阶段，审核交付物质量 |
| 项目结项 `closed` | 验收通过后结项，项目归档，释放剩余预算 |

### 状态扭转流程

| 功能点 | 说明 |
|---|---|
| 调研 → 立项 | 调研报告通过审核，确认项目可行，提交立项申请 |
| 立项 → 执行 | Backlog规划完成，预算分配到位，任务创建并发布 |
| 执行 → 验收 | 所有关联任务状态为「已验收」或「已关闭」 |
| 验收 → 结项 | 项目验收通过，所有交付物审核合格 |
| 验收 → 执行 | 验收不通过，退回执行阶段补充交付物 |
| 结项 → 归档 | 结项后自动归档，项目不可再编辑 |

### 状态扭转条件

| 当前状态 | 目标状态 | 扭转条件 |
|---|---|---|
| 调研阶段 | 立项阶段 | 调研文档提交并通过审核 |
| 立项阶段 | 项目执行 | Backlog阶段定义完成 + 至少1个任务已发布 |
| 项目执行 | 项目验收 | 所有关联任务状态为「已验收」或「已关闭」 |
| 项目验收 | 项目结项 | 验收审核通过 |
| 项目验收 | 项目执行 | 验收审核不通过，退回补充交付 |
| 项目结项 | 归档 | 自动归档，不可逆转 |

### 状态颜色标识

| 状态 | 颜色 | 圆点色值 |
|---|---|---|
| 调研阶段 | 橙色 | `#f59e0b` |
| 立项阶段 | 紫色 | `#8b5cf6` |
| 项目执行 | 绿色 | `#10b981` |
| 项目验收 | 蓝色 | `#3b82f6` |
| 项目结项 | 灰色 | `#64748b` |

### 状态与任务的关系

| 功能点 | 说明 |
|---|---|
| 调研/立项阶段 | 可创建草稿任务，不可发布 |
| 项目执行阶段 | 可创建并发布任务，任务进入待开始/进行中 |
| 项目验收阶段 | 任务必须全部完成（已验收/已关闭），否则不可扭转 |
| 项目结项 | 释放冻结积分，剩余预算回收，项目归档只读 |
| Backlog关联 | 每个Backlog阶段对应一组任务，阶段扭转需对应任务全部完成 |

### 创建项目时的状态

| 功能点 | 说明 |
|---|---|
| 默认状态 | 草稿（创建表单中可选：草稿/进行中/已完成/已归档） |
| 草稿 | 项目信息可编辑，未进入Backlog流程 |
| 进行中 | 进入正式阶段流转（调研→立项→执行→验收→结项） |
| 已完成 | 跳过流程直接标记完成（管理员操作） |
| 已归档 | 项目归档只读 |

## 关键函数

| 功能点 | 说明 |
|---|---|
| `renderProjects()` | 渲染项目列表（含筛选、排序、统计） |
| `openProjectModal()` | 打开创建项目抽屉 |
| `openProjectDetail(projectId)` | 打开项目详情侧滑面板 |
| `closeProjectDetail()` | 关闭侧滑面板 |
| `openBonusModal(projectId)` | 打开追加奖励面板 |
| `goToProjectTasks(projectId)` | 跳转任务管理并筛选该项目任务 |
| `addBacklogStage()` | 添加Backlog阶段 |
| `renderBacklogStages()` | 渲染Backlog阶段列表 |
| `initProjectMembers()` | 初始化项目成员选择器 |
| `getAllUsers()` | 获取所有用户列表 |
