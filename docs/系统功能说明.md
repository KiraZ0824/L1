# Remi AI 系统功能说明

---

## 一、工作台

### 需求描述
工作台是系统核心操作面板，集任务管理、项目概览、时间线追踪、燃尽图分析和积分监控于一体，为用户提供一站式项目协作视图。

### 功能说明

#### Backlog 视图

| 字段 | 类型 | 说明 |
|------|------|------|
| 编号 | 文本 | 自动生成，格式为 RemiBD001，递增 |
| 标题 | 文本 | 任务名称，可点击进入任务详情 |
| 优先级 | 标签 | P0/P1/P2/P3，按优先级高低排序展示 |
| 项目 | 标签 | 任务所属项目名称 |
| 状态 | 标签 | 待开始/进行中/待审核/驳回，带状态颜色标识 |
| RP | 数字 | 任务奖励积分数值 |
| 开始时间 | 日期 | 任务创建时间 |
| 截止时间 | 日期 | 任务截止日期，逾期显示红色 |
| 更新时间 | 日期 | 任务最近更新时间 |
| 负责人 | 文本 | 任务负责人姓名 |

#### 任务视图（看板/列表）

| 字段 | 类型 | 说明 |
|------|------|------|
| 列标题 | 文本 | 看板按状态分列：待开始、进行中、待审核、驳回、已验收、已关闭 |
| 任务数量 | 数字 | 每列括号内显示该状态下任务数 |
| 任务标题 | 文本 | 任务名称，可点击进入详情 |
| 项目标签 | 标签 | 任务所属项目，主题色背景 |
| 优先级 | 文本 | P0/P1/P2/P3 |
| 状态标签 | 标签 | 当前状态，带颜色 |
| 负责人 | 文本 | 任务负责人 |
| 截止日期 | 日期 | 逾期显示红色加粗 |
| 操作菜单 | 按钮 | 三点菜单，根据状态提供不同操作 |

#### 项目视图（阶段看板/项目总览）

| 字段 | 类型 | 说明 |
|------|------|------|
| 项目切换 | 按钮组 | 点击切换不同项目，当前项目高亮 |
| 项目信息栏 | 文本 | 展示当前项目名称、描述、负责人、预算 |
| 阶段标题 | 文本 | 调研阶段、立项阶段、项目执行、项目验收、项目结项 |
| 任务数量 | 数字 | 每阶段下当前项目的任务数 |
| 任务标题 | 文本 | 任务名称，可点击进入详情 |
| 优先级 | 文本 | P0/P1/P2/P3 |
| 状态标签 | 标签 | 当前状态，带颜色 |
| 负责人 | 文本 | 任务负责人 |
| 截止日期 | 日期 | 逾期显示红色加粗 |
| 项目名称 | 文本 | 可点击进入项目详情 |
| 当前阶段 | 文本 | 调研/立项/执行/验收/结项 |
| 项目进度 | 进度条 | 基于预算使用率，主题色填充，显示百分比 |
| 开始时间 | 日期 | 项目开始日期 |
| 结束时间 | 日期 | 项目结束日期 |
| 描述 | 文本 | 项目背景和范围描述 |
| 更多操作 | 按钮 | 点击进入项目详情 |

#### 时间线视图

以甘特图形式展示项目和任务的时间跨度，帮助用户直观了解各项目/任务的时间安排和重叠情况。支持项目模式和任务模式两种视图切换，任务模式下可按项目筛选，只展示指定项目下的任务时间线。时间轴自适应展示日期范围，条形图横向跨度对应实际起止时间，不同项目/任务纵向排列，便于对比时间重叠情况。

| 字段 | 类型 | 说明 |
|------|------|------|
| 模式切换 | 按钮 | 项目/任务两种模式，项目模式展示各项目时间跨度，任务模式展示各任务时间跨度 |
| 项目筛选 | 下拉框 | 任务模式下可按项目筛选，仅展示指定项目的任务时间线 |
| 时间轴 | 日期 | 横轴展示日期范围，自适应起止时间跨度 |
| 项目/任务条 | 条形图 | 纵向排列，横向跨度表示起止时间，不同条形图对应不同项目/任务 |
| 条形标签 | 文本 | 条形图上展示项目/任务名称 |

#### 燃尽图视图

以柱状图展示季度维度的任务燃尽情况，帮助团队把控进度趋势和剩余任务量。每个季度柱状图从上到下依次堆叠三个数据段：新增任务（蓝色）、剩余任务（主题色）、已完成（绿色），各柱段内显示对应数值。Y轴刻度从0到50，步进10，通过柱状图高度可直观对比各季度的任务量变化趋势，判断项目进度是否健康。

| 字段 | 类型 | 说明 |
|------|------|------|
| 季度标签 | 文本 | Q1、Q2、Q3、Q4 四个季度 |
| 新增任务 | 柱段 | 蓝色，展示该季度新增任务数，显示+数值 |
| 剩余任务 | 柱段 | 主题色，展示该季度剩余任务数，显示数值 |
| 已完成 | 柱段 | 绿色，展示该季度已完成任务数，显示-数值 |
| Y轴刻度 | 数字 | 0~50，步进10，标识任务量级 |
| 图例 | 标识 | 顶部展示已完成、预测、剩余任务、新增任务四项图例说明 |

#### 积分概况

| 字段 | 类型 | 说明 |
|------|------|------|
| 我的总积分 | 数字 | 当前积分余额（RP） |
| 本月获得 | 数字 | 本月新增积分数 |
| 累计任务 | 数字 | 累计完成任务数 |
| 近期积分变动 | 列表 | 最近4条积分变动记录 |
| 查看全部 | 按钮 | 跳转至积分中心 |

#### 积分变动趋势

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期范围 | 日期 | 横轴展示近14天日期 |
| 积分值 | 数字 | 纵轴展示每日积分变动值 |
| 折线 | 线图 | 橙色折线连接各日数据点 |
| 累计积分 | 数字 | 右上角显示14天累计积分 |

### 交互逻辑
1. Backlog 支持"全部/任务/审核"筛选，按优先级排序，点击行进入详情
2. 任务视图支持项目/优先级筛选，看板/列表可切换，卡片三点菜单根据状态动态显示操作项
3. 项目视图支持阶段看板/项目总览切换，阶段看板展示当前选中项目的任务（按阶段分列），可通过项目切换按钮切换项目；项目总览以列表形式展示所有项目
4. 时间线支持项目/任务模式切换，任务模式可按项目筛选
5. 燃尽图按季度堆叠展示新增、剩余、已完成三类数据
6. 积分概况点击"查看全部"跳转积分中心

### 异常说明
1. 任务截止日期逾期且未完成时，日期显示红色加粗；看板卡片逾期时边框变红
2. 项目总览进度条统一使用主题色，不再使用红色告警色
3. 燃尽图各季度数据结构需保持一致（均含新增、剩余、已完成三段），避免柱状图渲染异常
4. 视图切换时若容器未初始化，渲染函数需做容错判断（container 为空时 return）

## 二、Remi AI

### 需求描述
提供 AI 对话交互界面，支持历史对话管理、技能选择、项目资料引用和产出物预览，帮助用户通过自然语言完成代码开发、日常办公和设计创意等任务。

### 功能说明

#### 对话列表

| 字段 | 类型 | 说明 |
|------|------|------|
| 搜索框 | 输入框 | 搜索对话标题 |
| 新建对话 | 按钮 | 创建新对话 |
| Tab切换 | 按钮 | 历史对话/收藏对话 |
| 对话项 | 列表项 | 标题、预览内容、时间，右键菜单（重命名/收藏/删除） |
| 收起按钮 | 按钮 | 收起/展开对话列表 |

#### 聊天面板

| 字段 | 类型 | 说明 |
|------|------|------|
| 对话标题 | 文本 | 当前活跃对话标题 |
| 消息列表 | 列表 | 用户/AI 消息交替展示 |
| 引用文档 | 卡片 | AI 回复中的引用来源，含文档名、相关度、摘要片段 |
| 查看产出 | 按钮 | 打开产出物预览面板 |
| 技能选择 | 按钮 | 打开技能下拉选择（单选，限1个） |
| 项目资料 | 下拉框 | 引用预设项目文档 |
| 消息输入框 | 输入框 | Enter 发送消息 |
| 空状态 | 展示 | Remi 头像、分类按钮（代码开发/日常办公/设计创意）、快捷技能标签 |

#### 产出物预览

| 字段 | 类型 | 说明 |
|------|------|------|
| 产出标题 | 文本 | 产出物名称 |
| 预览内容 | 视图 | 支持 xlsx/docx/pdf/md/html/txt 格式渲染 |
| 关闭按钮 | 按钮 | 关闭预览面板 |

### 交互逻辑
1. 点击对话项切换活跃对话，标题和消息列表同步更新
2. 对话项右键菜单支持重命名、收藏/取消收藏、删除
3. 消息输入框 Enter 发送，支持选择技能和引用项目资料后发送
4. AI 回复含引用文档时展示引用卡片，点击"查看产出"打开预览面板
5. 空状态点击分类按钮或快捷技能标签可快速发送消息

### 异常说明
1. 技能选择超过1个时，系统自动截取第一个并提示限制
2. 产出物格式不支持时，预览面板显示格式提示信息
3. 对话列表为空时展示空状态引导
4. 删除对话需确认，防止误删

| 所属部门 | 下拉框 | 负责人部门 |

| 字段 | 类型 | 说明 |
|------|------|------|
| 奖励分配列表 | 动态行 | 人员选择+金额+原因，可添加多行 |
| 审核人 | 下拉框 | 选择审核人 |
| 发起申请 | 按钮 | 提交奖励申请 |

### 交互逻辑
1. 列表支持搜索、状态/负责人筛选、排序，点击行进入详情
2. 关联任务列点击跳转任务管理页并自动筛选该项目
3. 创建项目时 Backlog 阶段可动态增删、上下排序
4. 项目成员默认填充苏思远和张永成，通过下拉框添加（已选不重复），点 × 删除
5. 追加奖励支持多行分配，提交后进入审核流程

### 异常说明
1. 创建项目必填字段（名称、描述、负责人、预算、日期、Backlog）为空时弹出提示
2. 项目成员下拉框已选用户不重复出现
3. Backlog 阶段至少保留一个，不可全部删除
4. 预算使用率超过100%时进度条需异常标记
5. 追加奖励金额合计不可超过项目剩余预算

## 四、任务管理

### 需求描述
提供任务全流程管理，涵盖创建、发布、编辑、提交审核、审核通过/驳回、关闭等环节，支持看板和列表两种视图，按状态流转驱动任务推进。

### 功能说明

#### 看板视图

| 字段 | 类型 | 说明 |
|------|------|------|
| 列标题 | 文本 | 草稿/待开始/进行中/待审核/驳回/已验收/已关闭 |
| 任务卡片 | 卡片 | 优先级标记、标题、描述、负责人、奖励RP、交付形式 |
| 操作按钮 | 按钮 | 根据状态动态显示（编辑/发布/处理/审核/关闭） |

#### 列表视图

| 字段 | 类型 | 说明 |
|------|------|------|
| 任务 | 文本 | 任务标题，可点击进入详情 |
| 项目 | 文本 | 所属项目 |
| 优先级 | 文本 | P0/P1/P2/P3 |
| 项目阶段 | 文本 | 所属 Backlog 阶段 |
| 任务状态 | 标签 | 当前状态，带 bl-status 样式 |
| 负责人 | 文本 | 任务负责人 |
| 奖励 | 数字 | 任务积分奖励 |
| 截止日期 | 日期 | 逾期显示红色 |
| 操作 | 按钮 | 三点下拉菜单 |

#### 筛选区

| 字段 | 类型 | 说明 |
|------|------|------|
| 搜索 | 输入框 | 按任务标题搜索 |
| 项目筛选 | 下拉框 | 按所属项目筛选 |
| 优先级筛选 | 下拉框 | P0/P1/P2/P3 |
| 状态筛选 | 下拉框 | 草稿/待开始/进行中/待审核/驳回/已验收/已关闭 |
| 负责人筛选 | 下拉框 | 按负责人筛选 |

#### 任务详情面板

| 字段 | 类型 | 说明 |
|------|------|------|
| 编号 | 文本 | 任务唯一标识 |
| 状态 | 标签 | 当前状态 |
| 优先级 | 标签 | P0/P1/P2/P3 |
| 所属项目 | 文本 | 项目名称 |
| Backlog | 文本 | 所属阶段 |
| 负责人 | 文本 | 任务负责人 |
| 截止日期 | 日期 | 任务截止时间 |
| 奖励 | 数字 | 积分奖励 |
| 交付形式 | 文本 | 交付方式 |
| 描述 | 文本 | 任务详细描述 |
| 完成时间 | 日期 | 任务完成时间 |

#### 创建任务弹窗

| 字段 | 类型 | 说明 |
|------|------|------|
| 标题 | 文本 | 必填 |
| 描述 | 文本域 | 必填 |
| 所属项目 | 下拉框 | 必填 |
| Backlog | 下拉框 | 必填，联动项目阶段 |
| 优先级 | 下拉框 | 必填，P0/P1/P2/P3 |
| 负责人 | 下拉框 | 任务负责人 |
| 截止日期 | 日期 | 必填 |
| 奖励(RP) | 数字 | 必填 |
| 交付形式 | 文本 | 交付方式 |
| 预期工作量 | 文本 | 预计工时 |
| 验收标准 | 文本域 | 验收要求 |

### 交互逻辑
1. 状态流转：草稿→发布→待开始→进行中→提交审核→待审核→通过(已验收)/驳回→重新提交→关闭
2. 不同状态显示不同操作按钮：草稿可编辑/发布，进行中可编辑/处理/关闭，待审核可审核/关闭，驳回可编辑/处理/关闭，已验收可关闭
3. 处理任务时填写完成说明并上传交付物，提交后状态变为待审核
4. 审核任务时支持多人奖励分配，修改金额需填写原因，可驳回或通过
5. 关闭任务需填写关闭原因

### 异常说明
1. 创建/编辑任务必填字段为空时弹出提示
2. 审核驳回时必须填写驳回原因
