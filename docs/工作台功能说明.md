# 工作台功能说明

---

## 一、Backlog 视图

### 需求描述
为用户提供统一的待办任务汇总视图，支持按类型筛选，展示所有未完成任务和待审核任务的完整信息，便于快速了解当前工作全貌。

### 功能说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 编号 | 文本 | 自动生成，格式为 RemiBD001、RemiBD002，递增 |
| 标题 | 文本 | 任务名称，可点击进入任务详情 |
| 优先级 | 标签 | P0/P1/P2/P3，按优先级高低排序展示 |
| 项目 | 标签 | 任务所属项目名称 |
| 状态 | 标签 | 待开始/进行中/待审核/驳回，带状态颜色标识 |
| RP | 数字 | 任务奖励积分数值 |
| 开始时间 | 日期 | 任务创建时间 |
| 截止时间 | 日期 | 任务截止日期，逾期显示红色 |
| 更新时间 | 日期 | 任务最近更新时间 |
| 负责人 | 文本 | 任务负责人姓名 |

### 交互逻辑
1. 顶部支持"全部/任务/审核"三种筛选模式切换，"全部"展示所有未完成任务，"任务"仅展示非审核状态任务，"审核"仅展示待审核任务
2. 列表默认按优先级从高到低排序（P0 > P1 > P2 > P3）
3. 点击任务行任意位置可进入任务详情
4. 截止日期已逾期且任务未完成时，日期显示为红色加粗

---

## 二、任务视图

### 需求描述
提供任务的看板和列表两种展示方式，支持按项目和优先级筛选，帮助用户从不同维度管理任务进度。

### 功能说明

#### 看板视图

| 字段 | 类型 | 说明 |
|------|------|------|
| 列标题 | 文本 | 按状态分列：待开始、进行中、待审核、驳回、已验收、已关闭 |
| 任务数量 | 数字 | 每列括号内显示该状态下的任务数 |
| 任务标题 | 文本 | 任务名称，可点击进入详情 |
| 项目标签 | 标签 | 任务所属项目，主题色背景 |
| 优先级 | 文本 | P0/P1/P2/P3 |
| 状态标签 | 标签 | 当前状态，带颜色 |
| 负责人 | 文本 | 任务负责人 |
| 截止日期 | 日期 | 逾期显示红色加粗 |
| 操作菜单 | 按钮 | 三点菜单，根据状态提供不同操作（编辑/提交审核/审核/重新提交/查看详情） |

#### 列表视图

| 字段 | 类型 | 说明 |
|------|------|------|
| 标题 | 文本 | 任务名称，可点击进入详情 |
| 项目 | 文本 | 所属项目名称 |
| 优先级 | 文本 | P0/P1/P2/P3 |
| 负责人 | 文本 | 任务负责人 |
| 状态 | 文本 | 当前状态文字描述 |
| 截止日期 | 日期 | 逾期显示红色加粗 |

### 交互逻辑
1. 顶部支持按项目筛选（下拉框，默认全部项目）和按优先级筛选（P0/P1/P2/P3）
2. 右上角支持"看板/列表"视图切换，看板为默认视图
3. 看板视图中任务卡片逾期时边框显示红色
4. 看板卡片右上角三点菜单根据任务状态动态显示操作项
5. 列表视图支持关键词搜索，匹配任务标题和描述
6. 点击任意任务卡片或列表行可进入任务详情

---

## 三、项目视图

### 需求描述
提供项目的阶段看板和总览两种展示方式，帮助用户从阶段维度和全局维度了解项目进展。

### 功能说明

#### 阶段看板

| 字段 | 类型 | 说明 |
|------|------|------|
| 阶段标题 | 文本 | 调研阶段、立项阶段、项目执行、项目验收、项目结项 |
| 任务数量 | 数字 | 每阶段下任务总数 |
| 任务标题 | 文本 | 任务名称，可点击进入详情 |
| 项目标签 | 标签 | 任务所属项目，主题色背景 |
| 优先级 | 文本 | P0/P1/P2/P3 |
| 状态标签 | 标签 | 当前状态，带颜色 |
| 负责人 | 文本 | 任务负责人 |
| 截止日期 | 日期 | 逾期显示红色加粗 |

#### 项目总览

| 字段 | 类型 | 说明 |
|------|------|------|
| 项目名称 | 文本 | 项目名称，可点击进入项目详情 |
| 当前阶段 | 文本 | 项目所处阶段（调研/立项/执行/验收/结项） |
| 项目进度 | 进度条 | 基于预算使用率计算，主题色填充，显示百分比 |
| 开始时间 | 日期 | 项目开始日期 |
| 结束时间 | 日期 | 项目结束日期 |
| 描述 | 文本 | 项目背景和范围描述，超长省略 |
| 更多操作 | 按钮 | 点击进入项目详情 |

### 交互逻辑
1. 顶部支持按项目筛选（下拉框，默认全部项目）
2. 右上角支持"阶段看板/项目总览"视图切换，阶段看板为默认视图
3. 阶段看板按五个阶段分列，每列展示该阶段下的任务卡片
4. 项目总览以列表形式展示所有项目，点击项目名称或操作按钮可进入项目详情
5. 筛选下拉框切换时根据当前视图模式自动渲染对应内容

## 四、时间线视图

### 需求描述
以甘特图形式展示项目和任务的时间跨度，帮助用户直观了解各项目/任务的时间安排和重叠情况。

### 功能说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 模式切换 | 按钮 | 项目/任务两种模式 |
| 项目筛选 | 下拉框 | 任务模式下可按项目筛选（默认全部） |
| 时间轴 | 日期 | 横轴展示日期范围 |
| 项目/任务条 | 条形图 | 纵向排列，横向跨度表示起止时间 |
| 项目名称 | 文本 | 条形图上显示项目/任务名称 |

### 交互逻辑
1. 左上角支持"项目/任务"模式切换，项目模式展示各项目时间跨度，任务模式展示各任务时间跨度
2. 任务模式下出现项目筛选下拉框，可按项目筛选任务
3. 时间轴自适应展示日期范围，条形图横向跨度对应实际起止时间

## 五、燃尽图视图

### 需求描述
以柱状图展示季度维度的任务燃尽情况，帮助团队把控进度趋势和剩余工作量。

### 功能说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 季度标签 | 文本 | Q1、Q2、Q3、Q4 |
| 剩余工作 | 柱段 | 主题色，展示该季度剩余任务数 |
| 已完成 | 柱段 | 绿色，展示该季度已完成任务数 |
| 新增工作 | 柱段 | 蓝色，展示该季度新增任务数 |
| Y轴刻度 | 数字 | 0~50，步进10 |

### 交互逻辑
1. 每个季度柱状图从上到下依次堆叠：新增工作（蓝色）、剩余工作（主题色）、已完成（绿色）
2. 各柱段内显示对应数值（如 +8、42、-18）
3. Y轴刻度从0到50，步进10

---

## 六、积分概况

### 需求描述
在工作台底部展示用户积分概览，包含总积分、本月统计、近期变动记录，方便快速了解积分状况。

### 功能说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 我的总积分 | 数字 | 当前积分余额（RP） |
| 本月获得 | 数字 | 本月新增积分数 |
| 累计任务 | 数字 | 累计完成任务数 |
| 近期积分变动 | 列表 | 展示最近4条积分变动记录 |
| 变动标题 | 文本 | 任务/奖励名称 |
| 变动类型 | 文本 | 任务奖励/额外奖励 |
| 变动日期 | 日期 | 积分变动时间 |
| 变动金额 | 数字 | 积分变动值，绿色显示 |
| 查看全部 | 按钮 | 跳转至积分中心 |

### 交互逻辑
1. 左侧卡片展示总积分、本月获得、累计任务三项核心指标
2. 右侧列表展示最近4条积分变动记录，每条包含标题、类型、日期、金额
3. 点击"查看全部"按钮跳转至积分中心页面

---

## 七、积分变动趋势

### 需求描述
以折线图展示近14天的积分变动趋势，帮助用户了解积分获取节奏。

### 功能说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 日期范围 | 日期 | 横轴展示近14天日期 |
| 积分值 | 数字 | 纵轴展示每日积分变动值 |
| 折线 | 线图 | 橙色折线连接各日数据点 |
| 填充区域 | 面积图 | 折线下方半透明橙色填充 |
| 累计积分 | 数字 | 右上角显示14天累计积分 |

### 交互逻辑
1. 图表自适应容器宽度，横轴均匀分布14天日期标签
2. Y轴刻度根据数据最大值动态显示
3. 网格线辅助阅读，包含顶部、中部、底部三条水平线
