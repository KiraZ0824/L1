# 资料中心功能需求说明

## 需求描述

资料中心用于统一展示平台内的知识文档与项目任务资料，支持按页签分类浏览、关键词搜索和链接跳转查看。页面保持当前上下文，不做内容编辑，仅提供资料索引与访问入口。

页面包含两个页签：知识文档、项目任务资料。默认进入后展示知识文档页签，并提供统一搜索框对列表进行模糊过滤。

## 列表字段说明

### 知识文档

| 字段名称 | 英文名称 | 说明 |
|---|---|---|
| 知识名称 | name | 知识文档标题，用于展示文档主名称 |
| 上传人 | uploader | 文档上传人员，用于记录资料归属与责任人 |
| 所属部门 | dept | 文档所属部门，用于展示来源部门 |
| 上传原文件名称 | originalFile | 原始上传文件名称，用于展示用户上传时的文件名 |
| 更新时间 | updatedAt | 最近更新时间，用于展示文档最新变更时间 |
| 知识地址链接 | link | 文档访问地址，点击后打开对应文档链接 |

### 项目任务资料

| 字段名称 | 英文名称 | 说明 |
|---|---|---|
| 任务标题 | title | 任务资料标题，用于展示任务对应资料名称 |
| 原文档名称 | originalName | 原始文件名称，用于展示任务资料的原始文件名 |
| 所属项目 | project | 任务所属项目，用于展示任务归属项目 |
| 任务负责人 | owner | 任务责任人，用于展示任务处理责任人 |
| 更新时间 | updatedAt | 最近更新时间，用于展示资料最新变更时间 |
| 资料链接 | link | 资料访问地址，点击后打开对应资料链接 |

## 异常情况说明

| 异常场景 | 处理说明 |
|---|---|
| 搜索后无匹配结果 | 表格显示“暂无匹配结果”，不展示空白列表 |
| 资料链接缺失或不可访问 | 链接入口不应误导为可打开状态，避免点击后无响应 |
| 页签切换失败 | 保持当前页签内容不变，避免页面空白或数据错乱 |
| 搜索框清空后 | 恢复展示全部数据 |
| 数据加载失败 | 保持页面结构可见，并提示当前数据暂不可用 |
| 链接打开失败 | 保留当前页面，不跳转到错误页或空白页 |

## UI界面

### 页面结构

- 页面标题：资料中心
- 页面副标题：知识文档 · 项目任务资料
- 页签区域：知识文档、项目任务资料
- 搜索区域：统一搜索框，提示文案为“搜索知识名称/原文档名称/项目/人员...“
- 列表区域：表格展示对应页签数据

### 视觉与交互

- 默认页签为知识文档，页签切换后仅替换列表内容
- 关键名称字段加粗展示，增强主信息识别
- 链接统一显示为“打开链接”
- 页面需保持当前上下文，不跳转到其他业务页面
