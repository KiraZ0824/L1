# 知识审核详情 功能说明

## 一、需求描述

知识上传后进入审核流程，审核人需要在「知识审核详情」页面查看知识的完整信息（包括上传人、贡献者、知识类型、附件、系统建议奖励等），并在审核流程节点上对待审核的知识进行驳回、拒绝或审核通过操作。审核详情页需完整呈现知识上传时填写的所有字段，同时以竖向流程图展示审核节点（发起 → 审核 → 自动抄送 → 结束），审核人可在流程节点上直接填写审核意见并执行审核动作。拒绝操作表示拒绝该上传申请，同时终止整个审核流程；驳回操作将知识退回给上传人修改；审核通过则流转至下一审核人，全部审核人通过后流程结束。

---

## 二、功能说明

| 功能点 | 说明 |
|--------|------|
| 基础信息展示 | 展示字段：审核状态标签（待审核/已通过/已驳回）、知识标题及编号、知识说明、知识上传人、所属部门、知识贡献者、所属项目、知识来源、上传时间、一级类型、二级类型、知识附件（含预览）、系统建议奖励（基础贡献值 · 难度系数 · 建议奖励RP） |
| 审核流程节点 | 竖向展示4个节点：发起 → 审核 → 自动抄送 → 结束，节点间用竖线连接 |
| 发起节点 | 展示上传人姓名及发起时间，状态为已完成 |
| 审核节点 | 展示所有审核人，以竖向排列，已审核的人在上方，未审核的人在下方 |
| 审核人状态 | 已审核显示"已通过"标签（绿色），未审核显示"待审核"标签（橙色） |
| 审核意见（已审核） | 已审核的审核人下方展示审核时间和审核意见 |
| 审核意见输入框 | 当前待审核人下方显示长文本输入框，用于填写审核意见 |
| 审核操作按钮 | 当前待审核人下方显示三个按钮：驳回（橙色线框）、拒绝（红色线框）、审核通过（蓝色线框），均为白底有色线框样式 |
| 自动抄送节点 | 展示自动抄送人员列表（来源于知识贡献者），以标签形式展示 |
| 结束节点 | 流程终点，无操作人信息 |
| 审核通过 | 记录审核意见（未填写则默认"同意"）和审核时间，标记当前审核人为已通过，若全部审核人通过则流程结束；若仍有未审核人则提示"等待其他审核人处理" |
| 驳回 | 必须填写审核意见，记录意见和时间，知识状态变为已驳回，退回给上传人修改 |
| 拒绝 | 必须填写审核意见，记录意见和时间，知识状态变为已驳回，后续所有未完成节点标记为已完成，流程立即终止 |
| 关闭按钮 | 关闭审核详情页面，返回列表 |

## 三、异常说明

| 异常场景 | 处理方式 |
|----------|----------|
| 驳回时未填写审核意见 | 弹窗提示"请填写审核意见"，阻止操作执行 |
| 拒绝时未填写审核意见 | 弹窗提示"请填写审核意见"，阻止操作执行 |
| 审核通过时未填写审核意见 | 不强制要求，默认审核意见为"同意" |
| 审核人重复操作 | 已审核的审核人不再显示操作按钮，无法重复提交 |
| 审核数据不存在 | 审核详情页面无法打开，无展示内容 |
| 审核人列表为空 | 审核节点不展示操作按钮，仅显示节点标题 |
| 拒绝操作后流程终止 | 后续审核节点、自动抄送节点、结束节点均标记为已完成，不再显示操作入口 |
| 附件预览失败 | 预览功能依赖文件服务，若文件不可访问则提示预览失败 |

## 四、上传知识异常说明

| 异常场景 | 处理方式 |
|----------|----------|
| 未选择文件即提交 | 弹窗提示"请选择要上传的文件"，阻止提交 |
| 未选择知识贡献者即提交 | 弹窗提示"请选择知识贡献者"，阻止提交 |
| 文件格式不支持 | 文件选择器仅接受指定格式（DOC、DOCX、PDF、TXT、PPT、PPTX、XLS、XLSX、MD、CSV），非支持格式的文件无法选择 |
| 文件过大 | 文件大小超出系统限制时提示上传失败，建议压缩或拆分后上传 |
| 知识贡献者下拉框搜索无结果 | 下拉列表显示"无匹配结果"，需调整搜索关键词或检查用户列表 |
| 重复添加同一文件 | 文件列表中展示所有已选文件，同一文件可重复添加，提交时需人工确认 |
| 审核流程预览未选择项目 | 审核节点不显示项目负责人，审核人为空，需选择项目后自动带入负责人 |
| 审核流程预览未选择审核人 | 审核节点仅显示"+"按钮，不展示审核人标签，需手动添加审核人 |
| 所属部门默认值错误 | 部门根据上传人自动带入，若用户信息缺失则显示空值，需手动选择 |
| 网络上传中断 | 文件上传过程中断时提示上传失败，需重新选择文件上传 |
| 知识说明超出字数限制 | 文本框无硬性字数限制，但建议控制在合理范围内，过长可能影响审核展示效果 |
