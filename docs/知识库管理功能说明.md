# 知识库管理功能说明

## 页面概述

| 功能点 | 说明 |
|---|---|
| 页面入口 | 侧边栏 → 知识库管理 |
| 页面 ID | `page-knowledge` |
| 当前 Tab | 向量数据管理（知识类型设置已迁移至基础配置） |
| Tab 切换函数 | `switchKbTab(el, 'vector')` |

## 筛选与搜索

| 功能点 | 说明 |
|---|---|
| 类型筛选 | 下拉选择：全部类型 / 技术文档 / 产品设计 / 案例分析 / 合规风控 / 模板 / 市场运营 / 未分类 |
| 状态筛选 | 下拉选择：全部状态 / 已向量化 / 待向量化 |
| 关键词搜索 | 输入框，按知识名称模糊搜索 |
| 筛选函数 | `vmGetFiltered()` — 组合类型、状态、关键词返回结果列表 |

## 数据表格

| 功能点 | 说明 |
|---|---|
| 知识编号 | `RemiKB001` 格式，自动生成 |
| 知识名称 | 文档名称，附带文件大小 |
| 类型 | 文档类型（技术文档/产品设计等） |
| 知识来源 | 文档来源（上传/导入等） |
| 一级类型 | 知识一级分类 |
| 二级类型 | 知识二级分类 |
| 所属部门 | 归属部门 |
| 上传人 | 上传者姓名 |
| 知识贡献者 | 知识贡献者姓名 |
| 分段 | 分段数量 |
| 维度 | 向量维度（如1536） |
| 状态 | 已向量化（绿点）/ 待向量化（黄点） |
| 更新于 | 最后更新时间 |
| 操作列 | 「查看分段」按钮 |
| 分页 | 支持分页浏览，控件 `vmTbody_pager` |
| 列设置 | 可自定义显示/隐藏列，控件 `vmTbody_colsel` |

## 知识分段详情弹窗

| 功能点 | 说明 |
|---|---|
| 打开方式 | 点击「查看分段」按钮 → `vmOpenModal(docId)` |
| 弹窗布局 | 左右两栏：左侧分段列表，右侧元数据面板 |
| 分段类型筛选 | 下拉选择：全部 / 父分段 / 子分段 |
| 分段搜索 | 输入框，在分段文本中搜索关键词 |
| 父分段展示 | 启用/禁用复选框、分段标签、字符数、召回次数、已编辑标签 |
| 子分段展开 | 点击展开/折叠按钮显示子分段 |
| 分段启用/禁用 | 复选框切换 → `vmToggleChunkEnabled(id, checked)` |
| 分段选中 | 点击分段 → `vmSelectChunk(chunkId)` → 右侧渲染详情 |
| 关闭弹窗 | `vmCloseModal()` |

## 元数据面板（右侧详情）

| 功能点 | 说明 |
|---|---|
| 分段内容 | 完整分段文本 |
| knowledge_type | 知识类型 |
| 原始文件名称 | 上传文件名 |
| 原始文件大小 | 文件大小 |
| 上传日期 | 上传时间 |
| 最后更新日期 | 最后修改时间 |
| 来源 | 文档来源 |
| 分段规则 | 切分策略（如按段落、按Token等） |
| 段落长度 | 设定的段落长度 |
| 平均段落长度 | 实际平均长度 |
| 段落数量 | 分段总数 |
| 召回次数 | 该文档被召回的次数 |
| 嵌入时间 | 向量化耗时 |
| 嵌入花费 | 向量化成本 |

## 知识类型数据（12大类）

| 功能点 | 说明 |
|---|---|
| 类型数量 | 12大类，已迁移至基础配置 → 知识类型配置 |
| 类型1 | 规范与标准（Standards & Policies）— 9个二级标签，15篇文档 |
| 类型2 | 商务方案（Business Proposals）— 8个二级标签，12篇文档 |
| 类型3 | 模板（Templates）— 13个二级标签，8篇文档 |
| 类型4 | 合同与法律文件（Legal & Contracts）— 10个二级标签，6篇文档 |
| 类型5 | 产品文档（Product Docs）— 10个二级标签，10篇文档 |
| 类型6 | 需求文档（Requirements）— 9个二级标签，10篇文档 |
| 类型7 | 技术文档（Technical Docs）— 12个二级标签，15篇文档 |
| 类型8 | 操作指南与演示（User Guides & Demos）— 9个二级标签，5篇文档 |
| 类型9 | 合规与风控（Compliance & Risk）— 12个二级标签，7篇文档 |
| 类型10 | 数据清单与数据库（Data & Directory）— 10个二级标签，9篇文档 |
| 类型11 | 分析与测算（Analysis & Modeling）— 12个二级标签，11篇文档 |
| 类型12 | 会议纪要（Meeting Notes）— 12个二级标签，4篇文档 |
| 数据定义 | `knowledgeTypeData` 数组 |
| 渲染函数 | `renderKnowledgeTypes()`（已迁移至基础配置） |

## 关键函数

| 功能点 | 说明 |
|---|---|
| `switchKbTab(el, tab)` | 切换知识库 Tab |
| `vmRenderList()` | 渲染向量数据列表 |
| `vmGetFiltered()` | 获取筛选后的文档列表 |
| `vmStatusInfo(status)` | 获取文档状态信息（标签+样式） |
| `vmOpenModal(docId)` | 打开分段详情弹窗 |
| `vmCloseModal()` | 关闭弹窗 |
| `vmRenderModalChunks()` | 渲染弹窗内的分段列表 |
| `vmSelectChunk(chunkId)` | 选中分段，渲染右侧详情 |
| `vmRenderMetaPanel(chunkId)` | 渲染分段元数据面板 |
| `vmToggleChunkEnabled(id, checked)` | 启用/禁用分段 |
| `vmToggleExpand(id)` | 展开/折叠子分段 |
| `vmGetDefaultChunks(doc)` | 获取文档的默认分段数据 |
| `renderKnowledgeTypes()` | 渲染知识类型表格（已迁移至基础配置） |
| `manageKbSubTags(index)` | 管理知识类型二级标签 |
| `toggleKbStatus(index, enabled)` | 切换知识类型启用状态 |
| `addKnowledgeType()` | 新增知识类型 |
