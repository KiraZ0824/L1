## 三、任务操作按钮（按状态）

| 任务状态 | 可用操作 | 函数 |
|---|---|---|
| 草稿 `draft` | 编辑、发布 | `editTask(id)`、`publishTask(id)` |
| 待开始 `todo` | 编辑 | `editTask(id)` |
| 进行中 `in_progress` | 处理、关闭 | `processTask(id)`、`confirmCloseTask(id)` |
| 待审核 `pending_review` | 审核、关闭 | `auditTask(id)`、`confirmCloseTask(id)` |
| 驳回中 `rejected` | 编辑、处理、关闭 | `editTask(id)`、`resubmitTask(id)`、`confirmCloseTask(id)` |
| 已验收 `done` | 关闭 | `confirmCloseTask(id)` |

### 任务操作关联函数
| 函数 | 用途 |
|---|---|
| `openTaskDetail(id)` | 打开任务详情 |
| `saveEditTask()` | 保存任务编辑 |

| `doResubmit()` | 重新提交 |

| `doCloseTask()` | 确认关闭 |

| `auditRewardTask(id)` | 知识奖励审核 |

## 备注

当前权限面板为**静态展示态**，`savePermissions()` 仅弹出提示，未做真正的 RBAC 运行时校验。要实现真实权限控制，需要在以下位置接入权限判断：

1. `navigateTo(page)` — 页面路由级权限
2. `getTaskButtons(t)` — 任务操作按钮级权限
3. 各 `open*Modal()` 函数 — 创建/编辑操作权限
4. `switchAdminTab(tab)` / `switchPTConfigTab(tab)` — 配置页面Tab权限
5. `showPermissionPanel(role)` — 角色权限编辑入口
