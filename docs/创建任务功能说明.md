# 创建任务 功能说明

## 一、需求描述

用户在项目中需要创建任务时，点击「创建任务」按钮，系统以抽屉式面板从右侧滑入，展示创建任务表单。表单顶部提供「任务类型」下拉切换，支持两种模式：协作任务和知识上传。选择协作任务时，展示完整的任务创建表单；选择知识上传时，动态切换为知识上传表单，与独立的「上传知识」界面完全一致。底部操作按钮统一右下角对齐，取消+提交。

---

## 二、通用功能说明

| 功能点 | 说明 |
|--------|------|
| 抽屉式面板 | 从右侧滑入，宽度560px，顶部展示标题"创建任务"和关闭按钮，点击关闭按钮收起 |
| 任务类型切换 | 顶部下拉选择框，两个选项：协作任务（默认）、知识上传，切换时动态更换下方表单内容 |
| 底部按钮 | 右下角对齐：取消（btn-ghost透明背景文字按钮）+ 提交（btn-primary蓝色实心），协作任务显示"创建任务"，知识上传显示"确认上传" |

---

## 三、协作任务功能说明

| 功能点 | 是否必填 | 说明 |
|--------|----------|------|
| 任务编号 | - | 系统自动生成，不可编辑，创建任务后生成，输入框只读展示"创建任务后生成" |
| 任务标题 | 是 | 文本输入框，placeholder提示"输入任务标题（≤100字符）" |
| 任务描述 | 是 | 多行文本框，placeholder提示"详细描述任务内容" |
| 所属项目 | 是 | 下拉选择，选项来自项目列表 |
| 所属Backlog | 是 | 下拉选择：调研阶段、立项阶段、项目执行、项目验收、项目结项 |
| 优先级 | 是 | 下拉选择：P0紧急、P1高、P2中（默认）、P3低 |
| 任务负责人 | 否 | 下拉选择人员列表 |
| 截止日期 | 是 | 日期选择器 |
| 预计奖励(RP) | 否 | 数字输入框，placeholder提示"≤项目预算余额" |
| 交付形式 | 否 | 下拉选择：附件、文档链接、无需交付 |
| 预期工作量 | 否 | 数字输入框，placeholder提示"单位：人天" |
| 验收标准 | 是 | 多行文本框，placeholder提示"任务完成时对照验收的标准描述" |
| 提交 | - | 点击"创建任务"按钮，关闭抽屉并提示"任务创建成功！" |

---

## 四、知识上传功能说明

| 功能点 | 是否必填 | 说明 |
|--------|----------|------|
| 知识编号 | - | 系统自动生成，不可编辑，审核通过后生成，输入框只读展示"审核通过后生成" |
| 知识上传人 | - | 系统自动填充当前登录用户，不可编辑 |
| 所属部门 | 是 | 下拉选择，根据上传人自动带入对应部门 |
| 知识贡献者 | 是 | 支持下拉搜索（按部门/姓名），支持多选，以标签形式展示 |
| 选择文件 | 是 | 支持多选，accept限制格式：DOC、DOCX、PDF、TXT、PPT、PPTX、XLS、XLSX、MD、CSV |
| 知识说明 | 否 | 多行文本框 |
| 所属项目 | 否 | 下拉选择项目列表，选择后自动触发审核流程预览更新 |
| 知识来源 | 是 | 下拉选择：员工创作、APEX专家、AI辅助、外部资料 |
| 一级类型 | 是 | 下拉选择，从知识类型对照表（knowledgeTypeData）动态生成 |
| 二级类型 | 是 | 下拉选择，根据一级类型联动更新可选二级类型 |
| 奖励值 | 否 | 数字输入框 |
| 奖励上限动态计算 | - | 切换一级类型（updateSubTagSelect）或二级类型（updateRewardUpperLimit）时自动重算，公式：基础贡献值×30+难度系数×1.5，右侧展示"此知识类型的奖励上限额：X RP（基础贡献值Y × 30 + 难度系数Z × 1.5）" |
| 审核流程预览 | - | 垂直纵向4节点：发起→审核→自动抄送→结束，节点间竖线连接。审核节点可添加/删除审核人（选项目后自动带入项目负责人，"+"按钮可手动添加），抄送节点自动展示已选知识贡献者 |
| 提交 | - | 点击"确认上传"按钮，校验通过后提示上传成功并展示文件名、上传人、贡献者、所属项目、知识来源、一级类型、二级类型信息 |

---

## 五、知识上传异常说明

| 异常场景 | 处理方式 |
|----------|----------|
| 未选择文件即提交 | alert提示"请选择要上传的文件"，阻止提交 |
| 未选择知识贡献者即提交 | alert提示"请选择知识贡献者"，阻止提交 |

---

## 六、交互说明

| 交互场景 | 说明 |
|----------|------|
| 打开创建任务抽屉 | 点击「创建任务」按钮，抽屉从右侧滑入，默认显示协作任务表单 |
| 切换为知识上传 | 协作任务表单隐藏，调用renderKnowledgeUploadForm动态渲染知识上传表单，初始化contributor dropdown和审核流程预览 |
| 切换回协作任务 | 知识上传表单清空（innerHTML=''）并隐藏，恢复协作任务表单显示 |
| 知识类型联动 | 切换一级类型时调用updateSubTagSelect()更新二级类型选项，同时调用updateRewardUpperLimit()更新奖励上限 |
| 切换二级类型 | 调用updateRewardUpperLimit()重新计算并展示奖励上限 |
| 选择所属项目（知识上传） | 调用updateAuditFlowPreview()，选项目时自动带入项目负责人为审核人，不选项目时清空审核人列表 |
| 关闭抽屉 | 点击关闭按钮或取消按钮，抽屉向右收起 |
